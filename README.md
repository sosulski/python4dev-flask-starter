# Programming in Python: Flask Starter

Starter project for Programming in Python and Fundamentals of App Development.

## Get started in Replit

1. Make sure you're signed in to Replit.
2. Open the class starter link from Brightspace and click **Import**.
3. If an AI Agent or chat panel opens, close it.
4. Click **Run**. A preview pane should show the "My App" home page. Click About and Help to check the links work.

## What's in this project

| File | What it does |
|---|---|
| `app.py` | The Flask app. Each route (`/`, `/about`, `/help`) shows one page. |
| `templates/index.html` | Your landing page. |
| `templates/about.html` | Your About page. |
| `templates/help.html` | Your Help page. |
| `static/style.css` | Colors and fonts for your pages. |
| `requirements.txt` | Tells Replit to install Flask. |
